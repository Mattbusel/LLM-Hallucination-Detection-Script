模型对哪些词没把握？

AI 写出的每个词都带有一个概率，概率低的地方就是它在猜。在下方选一个真实回答并拖动阈值，或者往下滚动，问你自己的问题。

下载原始响应（供 CLI 使用）
没把握的词，以及模型考虑过的候选

示例来自 examples/logprobs/ 中 Llama 3.1 8B Instruct 的真实响应。只要一个词的任一组成部分的概率（p = elogprob）低于阈值，这个词就会被标出，与 CLI 的做法完全一致。鼠标悬停或点按一个词，即可查看它的概率和候选。

你自己的问题

用你自己的密钥向模型提问。

这里只支持会返回 token 概率的 API。选一个提供商，粘贴密钥，问个问题，回答就会出现在上方，没把握的词都会被标出。

你的密钥只留在你的浏览器里。本页面没有服务器。密钥只会在提问的那次请求中，由你的浏览器直接发送给你选择的提供商。

除非你勾选“记住”，否则密钥不会被保存在任何地方；即使勾选，也只保存在这个浏览器里。

哪些提供商可以从浏览器直接调用

提供商浏览器调用
OpenAI可以。会响应来自本站的跨域请求。请使用会返回 logprobs 的模型，例如 gpt-4o-mini。
OpenRouter可以。允许任何网站调用。只有部分上游提供商会返回 logprobs，所以请求会要求 OpenRouter 路由到支持全部参数的提供商。
Together AI可以。允许任何网站调用。请求使用 Together 自己的 "logprobs": 3 格式。
本地 Ollama默认不行。Ollama 会拒绝来自其他网站的请求。请用 OLLAMA_ORIGINS=https://hallucination-highlighter.vercel.app 启动它，然后选择“自定义”，填入 http://localhost:11434/v1。浏览器在允许网站访问你本机之前，也可能会先询问你。或者直接用没有这种限制的 CLI。
Anthropic不行。它的 API 不返回 token 概率，因此没有可高亮的内容。

浏览器访问情况于 2026-09-30 从本站地址发起 CORS 预检请求确认。提供商可能会更改这些设置。

在终端里也能做

CLI 也能做到，内置相同提供商以及 vLLM 和 Ollama 的预设，而且没有浏览器的限制：

llm-token-visualizer --live "Who painted The Night Watch?" --provider openrouter
llm-token-visualizer --live "Who painted The Night Watch?" --provider ollama --model qwen2.5-coder:14b
